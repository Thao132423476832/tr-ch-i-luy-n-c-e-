# Trò chơi luyện bảng nhân 3

Ứng dụng dòng lệnh này giúp học sinh luyện tập bảng nhân 3 bằng tiếng Việt thông qua hình thức chatbot.

## Cách chạy chương trình

1. Mở Terminal (hoặc Command Prompt trên Windows).
2. Di chuyển tới thư mục chứa dự án:
   ```bash
   cd /duong/dan/toi/thu-muc/tr-ch-i-luy-n-c-e-
   ```
3. Chạy chatbot bằng Python:
   ```bash
   python chatbot_bang_nhan_3.py
   ```

## Cách tương tác

- Chatbot sẽ đặt các câu hỏi ngẫu nhiên liên quan tới bảng nhân 3.
- Bạn chỉ cần nhập câu trả lời và nhấn Enter.
- Có thể gõ `thoát` (hoặc `exit`, `quit`) bất cứ lúc nào để kết thúc.

Chúc bạn học tốt!
